# Privacy Policy for Competitive Problem Receiver

**Last Updated: 2026-11-06**

This Privacy Policy applies to the **Competitive Problem Receiver** plugin (hereinafter referred to as "the Plugin") developed by **Azathorpe** for JetBrains IDEs.

## 1. Data Collection and Usage
The Plugin **does not collect, store, or transmit any personal data** or telemetry to external servers.

## 2. Local File Storage
The Plugin listens on a local port to receive programming problem data from the *Competitive Companion* browser extension. To fulfill its core functionality, the Plugin will:
*   Receive data strictly on `localhost` (127.0.0.1).
*   Create and read configuration files in your local user directory.
*   Save the parsed programming problems to your local project folder.

All data processing and file operations are performed locally on your machine. No data is uploaded to the internet or shared with any third parties.

## 3. Third-Party Services
The Plugin does not integrate with any third-party analytics or advertising services.

## 4. Changes to This Policy
If this policy changes in the future, the updated version will be committed to this repository and reflected on the JetBrains Marketplace plugin page.

## 5. Contact
If you have any questions about this Privacy Policy, please open an issue on the GitHub repository: [https://github.com/Azathorpe/Competitive-Problem-Receiver](https://github.com/Azathorpe/Competitive-Problem-Receiver)

# Competitive Problem Receiver 插件隐私政策（中文参考）

**最后更新日期：2026-11-06**

本隐私政策适用于由 **Azathorpe** 为 JetBrains IDE 开发的 **Competitive Problem Receiver** 插件（以下简称“本插件”）。

## 1. 数据收集与使用
本插件**不收集、不存储、也不向外部服务器传输任何个人数据**或遥测数据。

## 2. 本地文件存储
本插件通过监听本地端口，接收来自 *Competitive Companion* 浏览器插件发送的编程题目数据。为了实现核心功能，本插件会：
*   仅在本地环回地址（`localhost` / `127.0.0.1`）接收数据。
*   在您的本地用户目录中创建和读取配置文件。
*   将解析后的题目数据保存到您本地的项目文件夹中。

所有的数据处理和文件操作均在您的本地计算机上完成。没有任何数据会被上传到互联网或与任何第三方共享。

## 3. 第三方服务
本插件不包含任何第三方分析或广告服务。

## 4. 隐私政策的变更
如果未来本政策发生变更，更新后的版本将提交到本仓库，并同步更新在 JetBrains Marketplace 的插件页面中。

## 5. 联系方式
如果您对本隐私政策有任何疑问，请在 GitHub 仓库中提交 Issue：[https://github.com/Azathorpe/Competitive-Problem-Receiver](https://github.com/Azathorpe/Competitive-Problem-Receiver)
